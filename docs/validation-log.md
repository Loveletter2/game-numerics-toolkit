# 我这张表错在哪

这是我自己拉的一张《鸣潮》配装表，算心、锁暝、守岸人三个角色的 25 秒输出轴。

表是测试服期间拉的。测试服到正式服之间改过东西，我当时不知道。下面三件事，是我后来一条条撞出来的。

---

## 一、防御系数，我多写了一个 1

我一开始用的防御公式是这样的：

```
(自己等级 + 100) / ((自己等级 + 100) + (对方等级 + 100))
```

很好记，两边都加 100，看着对称。

后来去翻敌人属性表，想确认一下 90 级怪的血量，顺手看了一眼防御那一栏：**1512**。

我愣了一下。按我这个写法，90 级敌人对应的数字应该是 8×190 = 1520。1512 是 8×189。

也就是说我自己那一侧加的是 100，敌人那一侧加的是 99。不对称。

回去拆官方公式才明白：自己这边是 `800 + 8×等级`，也就是 `8×(等级+100)`；敌人那边的防御值是 `8×(等级+99)`。两边都带一个 8，约掉了，最后只剩 +100 对 +99。

差别 0.26%。单看伤害根本看不出来，因为它是所有动作共用的一个常数，配装排序一点不变。这也是为什么我用这么久都没发现——**它不影响比较，只影响绝对值。**

---

## 二、大招的段数

这条差点被我放过。

核倍率的时候，我拿表里的总倍率去对官方数据，对上了，差 0.00%。准备收工的时候多看了一眼原始写法：

```
我的表：69.59% × 7 段 + 208.76%
官方：  60.89% × 8 段 + 208.76%
```

总倍率一个是 6.9589，一个是 6.9588，几乎一模一样。

但段数不一样。7 段和 8 段打出来的期望伤害一样，实际表现不一样：游戏里每段伤害各自向上取整，8 段比 7 段多一次取整的机会；暴击也是逐段判定，段数少的时候波动更大。

我当时算的是期望，所以这条对我来说"没影响"。但它其实是错的，只是错得刚好不影响我当时要看的东西。后来还是改了。

---

## 三、我改错了一次，又改回来

这条最丢人，但我觉得该写。

17 个动作的倍率要和官方技能对上。我图省事，用总倍率去匹配——把表里的算式加成一个数，去官方技能表里找最接近的那条。

有一条对上了：

```
表里  飞阙伤害  11.37% × 21 段 = 2.3877
官方  另一条    119.36% × 2 段 = 2.3872
```

差 0.02%。我当时觉得这就是同一件事，只是写法不同，于是把它改成了 119.36%×2。

后来按技能名逐条核对，才发现官方「飞阙伤害」的单段值**就是 11.37%**。我表里写得没错，21 段是段数——官方数据只给单段倍率，不给段数。

两个完全不相关的技能，加起来差了 0.13%。纯粹是巧合。

这次改动我回滚了。

---

## 现在我会多做一步

这三件事之后我改了个习惯：**核对之前先把口径对齐，而且先用名字对齐，再用数值验证。**

以前我是反过来的，先看数值像不像。问题是数值像可能只是巧合：差 8% 我会去查，差 0.02% 我直接就信了——**小的差距反而更危险**，因为它不会让你停下来。

第一条那个 0.26% 也是同一个道理。偏差小，所以我忽略了。第三条也是偏差小，所以我信了。一个是漏，一个是误判，坑是同一个。

---

## 还没解决的

`普攻·暝伞形·刻心念` 这一条，我表里算出来 775.70%，官方是 1551.41%。

正好差 2 倍，不是取整误差。

我还没搞清楚是漏了一段，还是复制的时候少乘了 2。这条暂时没动，因为改了就影响锁暝那一行的总伤，得先确认。

写在这里，提醒自己别忘了。
